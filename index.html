ROUTING DATA

BGP / Route Monitoring Layer

RouteViews provides current and near-real-time global BGP routing data for network operators and researchers. The connector is separated from the browser UI so a later backend can add cached BGP anomaly indicators without exposing credentials or exceeding public rate limits.

RIPE Atlas

Anonymous public API is queried for probe counts and connection status in Taiwan and nearby countries. Public measurements can later be used for ping, traceroute and reachability baselines.

OpenStreetMap / Overpass

The map attempts to load underwater telecommunications line objects around Taiwan from OpenStreetMap. Coverage depends on what has been openly mapped.

ROUTING

RouteViews

Current routing-system observations can be added through the RouteViews API. This gives network-level evidence around reachability and route changes rather than pretending to expose operator cable telemetry.
