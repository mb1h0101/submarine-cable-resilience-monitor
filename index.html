PROJECT CONTEXT

Why this exists

This project is an independent software reimplementation intended to make submarine-cable resilience concepts easier to inspect, discuss, and extend in civic-tech, research, and public-policy settings. The codebase is designed as a software demonstrator that can later connect to validated public datasets or authorized sensor feeds.
